# lm-portafolio

Portafolio del módulo 0373 · Lenguajes de marcas y sistemas de gestión de información

Aquí se irán guardando las prácticas del módulo.

## Estructura

```
lm-portafolio/
├── index.html      ← página de inicio
├── css/estilos.css ← estilos
├── js/app.js       ← muestra la fecha de hoy
├── img/favicon.svg ← icono de la pestaña
├── biciruta-web/   ← práctica UT 1 (BiciRuta)
├── README.md
└── .gitignore
```

## Cómo verlo

Abre la carpeta en VS Code, abre `index.html` y pulsa **Go Live** (Live Server).

## Proyectos

Cada práctica del módulo va en su propia carpeta:

| Carpeta | Práctica |
|---|---|
| `biciruta-web/` | UT 1 · Entorno de trabajo, depuración y control de versiones. Incluye su historial completo (rama `ofertas`, fusión y revert). Repositorio original: https://github.com/9nikiii/biciruta-web |
