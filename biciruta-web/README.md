# BiciRuta Web

Página web de **BiciRuta S.L.**, tienda de bicicletas y accesorios.

## Estructura

```
biciruta-web/
├── index.html            ← estructura y contenido
├── css/estilos.css       ← estilos
├── js/app.js             ← comportamiento
├── img/logo_biciruta.png ← logotipo
├── README.md
└── .gitignore
```

## Cómo verla

1. Abre la carpeta `biciruta-web` en Visual Studio Code.
2. Abre `index.html`.
3. Pulsa **Go Live** en la barra de estado (extensión Live Server) y la página se abrirá en el navegador en `http://127.0.0.1:5500/`.
